# simple-speedtest

Консольный скрипт на Python для замера скорости скачивания. Делает 10 последовательных
запросов к указанному адресу, дожидается полного ответа на каждый и выводит:

- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Требования

Python 3.7+. Внешних зависимостей нет — только стандартная библиотека.

## Запуск

```bash
git clone https://github.com/ak-umka/simple
cd simple-speedtest
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

> Некоторые сайты (например, Wikimedia) ограничивают частоту запросов и после пары скачиваний
> отвечают `429 Too many requests` — для замеров лучше брать специальные тестовые файлы.

Опции:

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `-n`, `--requests` | количество запросов | `10` |
| `-t`, `--timeout` | таймаут одного запроса, сек | `30` |

## Пример вывода

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 10

  # 1:     10.00 МБ     1460.5 мс     57.44 Мбит/с
  # 2:     10.00 МБ     1347.0 мс     62.27 Мбит/с
  ...
  #10:     10.00 МБ     1373.1 мс     61.09 Мбит/с

Успешных запросов:      10 из 10
Среднее время запроса:  1393.5 мс
Всего скачано:          100.00 МБ (104857600 байт)
Скорость скачивания:    60.20 Мбит/с (7.52 МБ/с)
```

## Единицы измерения

- **Время запроса** — миллисекунды (мс). Измеряется от отправки запроса до получения
  последнего байта тела ответа (включает DNS, установку соединения, TLS и скачивание).
- **Объём** — байты, а также человекочитаемо в двоичных единицах (1 КБ = 1024 Б,
  1 МБ = 1024 КБ).
- **Скорость** — **мегабиты в секунду (Мбит/с)**, где 1 Мбит = 1 000 000 бит — так
  же, как скорость указывают провайдеры и speedtest-сервисы. Рядом для удобства
  приведено значение в МБ/с (мегабайты, 10⁶ байт).

Скорость считается как `общий объём × 8 / суммарное время всех запросов`, то есть это
средневзвешенная скорость, а не среднее арифметическое скоростей отдельных запросов.

## Детали

- Запросы идут строго последовательно; тело ответа дочитывается полностью.
- Отправляются заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`,
  чтобы не получить ответ из кэша и считать реальные байты без сжатия.
- Неудачные запросы выводятся с ошибкой и не учитываются в статистике.
  Код возврата: `0` — все запросы успешны, `2` — часть с ошибками, `1` — все неуспешны.
